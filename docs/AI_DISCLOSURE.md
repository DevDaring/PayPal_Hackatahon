# AI disclosure

## Models used at runtime

| Purpose | Model (live demo) | Configurable via |
|---|---|---|
| Requirement drafting from plain language | `gemini-2.5-flash` via Gemini's OpenAI-compatible endpoint | `AI_PROVIDER`, `AI_BASE_URL`, `AI_MODEL`, `AI_API_KEY` |
| Quote term extraction with citations | same | same |
| Plain-English explanation of the computed comparison | same | same |
| Q&A side panel grounded in one request's evidence | same | same |
| OCR of image-only PDFs (optional) | same model, vision input | `OCR_PROVIDER`, `OCR_MODEL` |

Any OpenAI-compatible provider works (OpenAI, OpenRouter). With no provider configured, or `MOCK_AI=true`, the deterministic extractor and template explanations are used and the UI says so.

## What the model can and cannot do

- **Can:** read the text it is given and return JSON.
- **Cannot:** call tools, fetch URLs, read files or environment variables, execute commands, approve, pay, choose payees, or change budgets. Payment execution is a separate authenticated service.
- **Cannot override computation:** totals, arithmetic, pass/fail/unknown and ranking are computed in `domain/policy.py`. Explanations that contradict the computed recommendation are discarded and replaced by a template.

## Prompts

Versioned in `backend/quoteguard/ai/prompts.py` (`req-v2`, `extract-v4`, `explain-v2`, `chat-v1`). Changing a prompt changes its version, which invalidates the extraction cache (keyed by document hash + prompt + schema + parser version + model, scoped per workspace).

## Bounds

Timeouts (`AI_TIMEOUT_SECONDS`), max tokens (`AI_MAX_TOKENS`), a per-request call budget (`AI_MAX_CALLS_PER_REQUEST`), bounded retries on 429/5xx with key rotation, and a LangGraph recursion limit. Each call is logged with purpose, model, latency and token counts — not prompt content.

## What users see

- Every extracted value shows its method (`llm`, `rules`, `ocr+…`, `correction`) and model.
- Explanations are labelled “Plain-English summary by <model>” with the note that they summarise a deterministic result and are not the model's private reasoning.
- No confidence percentages are shown (none are calibrated); extraction status categories are used instead.

## Synthetic data

All supplier quotations are generated by `quoteguard/fixtures.py` (ReportLab) for fictitious businesses and are marked “DEMO SAMPLE — synthetic document”. Tax values are fixture terms, not tax advice. No real supplier logos, contracts or personal data are used.

## AI used to build the project

The codebase, documentation and tests were written with the help of an AI coding assistant (Anthropic Claude) directed by the author. Illustrations (`frontend/public/illustrations`, `submission/assets/cover.jpg`) were generated with Google Gemini image models from text prompts in `tools/gen_assets.py`.

## Limitations

- Evaluation uses one family of synthetic templates (24 cases); real supplier documents vary far more.
- Model output varies between runs; the stored evaluation history shows this (see `reports/`).
- OCR output has no coordinates and always requires human review before amounts count.
